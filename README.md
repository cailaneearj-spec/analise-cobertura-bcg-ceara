# Análise da Cobertura Vacinal da BCG no Ceará

Projeto de análise de dados sobre a cobertura vacinal da BCG nos 184 municípios do Ceará, entre 2018 e 2022.

O projeto foi desenvolvido com dados públicos do DATASUS, passando pela organização e conferência da base até a construção de um dashboard interativo no Power BI.

## Objetivo

Analisar a cobertura vacinal da BCG nos municípios do Ceará entre 2018 e 2022, acompanhando as mudanças ao longo dos anos e comparando os resultados entre os municípios.

## Ferramentas utilizadas

- **Excel:** organização, limpeza e conferência inicial dos dados.
- **Power BI:** análise dos dados e construção do dashboard.
  - **Power Query:** transformação e preparação da base dentro do Power BI.
  - **DAX:** criação das medidas utilizadas na análise.
- **DATASUS:** fonte dos dados utilizados no projeto.

  ## Como foi feito

O projeto foi desenvolvido em algumas etapas:

1. Coleta dos dados públicos de cobertura vacinal no DATASUS.
2. Organização e conferência da base no Excel.
3. Verificação de dados vazios, duplicados e valores fora do padrão.
4. Preparação da base no Power Query para facilitar a análise.
5. Criação de medidas no Power BI utilizando DAX.
6. Construção do dashboard com indicadores, gráficos, rankings e filtros interativos.

  ## Dashboard

O dashboard foi desenvolvido no Power BI para facilitar a visualização e comparação dos dados ao longo do período analisado.

Ele permite acompanhar a cobertura média da BCG, a evolução entre 2018 e 2022, comparar os municípios com maiores e menores médias e filtrar os resultados por município e ano.
